# Публикация «Карты клёва» в RuStore

## 0. Перед началом: подпись

1. Откройте https://github.com/melkagame1-lang/karta-kleva/settings/secrets/actions
2. Нажмите **New repository secret**.
3. Name: `SIGNING_PASSWORD`. Secret: пароль из файла `ПАРОЛЬ-КЛЮЧА.txt`, который я прислал. Нажмите **Add secret**.
4. Откройте вкладку **Actions** → «Собрать APK» → **Run workflow**.
5. Через 5–10 минут в **Releases** появятся:
   - `karta-kleva.aab` — для RuStore;
   - `karta-kleva.apk` — подписанный, для телефона.

**Храните ключ и пароль в надёжном месте.** Без них нельзя будет выпустить обновление: RuStore примет только версию с той же подписью.

**На своём телефоне.** Подписанная версия не установится поверх тестовой, потому что у них разные подписи. Порядок такой:
1. Сделайте резервную копию: «Дневник» → «Сохранить в файл».
2. Удалите старое приложение.
3. Установите новое.
4. «Загрузить из файла».

## 1. Аккаунт разработчика

1. Откройте https://console.rustore.ru и войдите через VK ID.
2. Выберите тип **Физическое лицо** и заполните форму. Регистрация бесплатная и проходит сразу.

## 2. Новое приложение

В консоли нажмите «Создать приложение». Тип — «Приложение», загрузите файл `karta-kleva.aab` (или `karta-kleva.apk`).

## 4. Данные и разрешения (раздел «Безопасность данных»)

- **Местоположение** (точное и приблизительное): показать пользователя на карте, отсортировать места по расстоянию, построить маршрут. Используется на устройстве, не передаётся разработчику.
- **Уведомления:** напоминания о хорошем клёве, сильном ветре и начале запретов. Включаются пользователем.
- **Фото** (выбор из галереи или камера, только по действию пользователя): прикрепить фото к записи дневника. Хранятся на устройстве.
- **Интернет:** погода, карты, маршруты, фото рыб, новости рыбоохраны.
- Персональные данные **не собираются**, аккаунтов нет, данные не передаются третьим лицам.

## Важно о картах

Подложки «Схема», «Рельеф», «Спутник» берутся с серверов Esri. Для приложения в магазине условия Esri предусматривают использование подложек с ключом. Ключ бесплатный:
1. Зарегистрируйтесь на developers.arcgis.com.
2. Создайте API key с доступом к Basemaps.
3. Пришлите ключ мне. Я впишу его в `www/config.js`, или впишите сами в поле `esriToken`.
