# Карта клёва — Android-приложение

Карта рыболовных мест России с прогнозом клёва на 7 дней.

## Что умеет

**Новое в версии 2:**
- **Архангельская область подробно**, особенно окрестности Северодвинска: Ягры и Яндова губа, река Ягорка, косы Никольского рукава, протоки дельты, Солза, Белое Озеро. Плюс Северная Двина в Архангельске, Мечка, устье Онеги, Лача, Кенозеро, Лёкшмозеро, Кожозеро, Пинега, Вага, Котлас, Мезень, Соловки. У каждого места написано, как добраться.
- **Маршрут** до любого места: от вас или от выбранного города. Линия на карте, километры и время в пути, кнопки «Яндекс Карты», «Яндекс Навигатор», «Google Карты».
- **Мои места**: нажмите на карту → «Сохранить место». Можно указать название, водоём, рыбу и заметки. Для своих мест работают прогноз клёва, приливы, маршрут и правила. Места хранятся на телефоне.
- **Вкладка «Рыбы»**: настоящие фотографии (iNaturalist и Wikimedia Commons, свободные лицензии, с указанием автора), как узнать рыбу, размеры, где ловить. Кнопка «Сохранить фото для офлайна».
- **Вкладка «Запреты»**: сроки из Правил рыболовства Северного бассейна. Статус «действует сейчас / скоро / не действует» считается по сегодняшней дате. Там же минимальные размеры, суточные нормы, особые зоны (дельта Двины, сёмужьи реки, зимовальные ямы) и свежие новости рыбоохраны с официальных сайтов.
- **Вкладка «Советы»**: 18 монтажей оснастки со схемами (в т.ч. микроджиг, джиг-риг, техасская и каролинская оснастки, вертушка, колебалка, воблер), 9 узлов, таблица грузов, как читать глубины и где стоит рыба, безопасность на льду и правила.
- **Глубины**: в карточке каждого места средняя и максимальная глубина и схема дна. На карте есть слой глубин морей.

- **Карта** с 41 рыболовным местом по всей России: от Калининграда до Камчатки. Цвет и цифра на поплавке — оценка клёва (1–5) на выбранный день.
- **Прогноз клёва на 7 дней** с объяснением простыми словами: почему клюёт хорошо или плохо.
- **Погода**: температура, ветер, осадки.
- **Давление** в мм рт. ст., как оно меняется за сутки, и график на неделю.
- **Фаза луны** с рисунком и подсказкой, как она влияет на клёв.
- **Приливы и отливы** для морских мест (Белое и Баренцево моря, Охотское море, Сахалин, Приморье).
- **Какая рыба водится** в каждом месте, **на что ловить** (наживка), **как ловить** (снасть и метод), совет и календарь сезона по месяцам.
- **Своя точка**: нажмите на любое место карты → «Прогноз здесь».
- Поиск по названию, региону и рыбе, фильтр по рыбе, избранное, кнопка «Я» (где я нахожусь), спутниковая карта.
- Без интернета показывается последний загруженный прогноз и контурная карта России.

Погода и приливы берутся из бесплатного сервиса Open-Meteo, ключ не нужен.

## Как получить APK (без установки Android Studio)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Создайте новый репозиторий и загрузите в него все файлы из этого архива (кнопка «Add file → Upload files»). Папка `.github` тоже должна попасть в репозиторий.
3. Откройте вкладку **Actions**. Сборка «Собрать APK» запустится сама (или нажмите «Run workflow»).
4. Через 5–10 минут откройте завершённую сборку и скачайте **karta-kleva-apk** внизу страницы.
5. Распакуйте архив, перекиньте `app-debug.apk` на телефон и установите. Android попросит разрешить установку из неизвестных источников — это нормально для своего приложения.

## Как собрать на компьютере (Android Studio)

Нужны Node.js 20+, JDK 21 и Android Studio.

```
npm install
npm run android:init
npm run android:open
```

В Android Studio нажмите ▶ Run (телефон подключён по USB) или Build → Build APK.

После правок в папке `www` выполните `npm run android:sync`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `www/data.js` | База рыб (наживка, метод, советы, сезон) и мест. Сюда легко добавить свои места. |
| `www/forecast.js` | Расчёт клёва, луны, восхода/заката, поиск приливов. |
| `www/app.js` | Карта и интерфейс. |
| `www/style.css` | Оформление (светлая и тёмная тема). |
| `www/basemap.js` | Контурная карта России для работы без интернета. |
| `www/rules.js` | Запреты, размеры, нормы, источники новостей рыбоохраны. |
| `www/tips.js` | Монтажи (схемы), узлы, грузы, глубины, безопасность. |
| `www/photos.js` | Загрузка фото рыб (iNaturalist, Википедия). |
| `www/fishart.js` | Описание внешнего вида рыб и запасные схемы без интернета. |

### Как считается клёв

Оценка 0–100 складывается из: стабильности давления (самое важное), силы и направления ветра, осадков, перепада температуры, фазы луны и сезона для каждой рыбы. Хищнику чуть добавляется при медленном падении давления. Оценка места — среднее по трём рыбам, которые клюют лучше всего.

Это подсказка по погоде и приметам, а не гарантия. Соблюдайте правила рыболовства своего региона и нерестовый запрет.

### Добавить своё место

В `www/data.js` в список `SPOTS` добавьте строку:

```js
{ id:"moe-ozero", n:"Моё озеро", r:"Тульская область", lat:54.20, lon:37.60, w:"lake",
  f:["shchuka","okun","karas"], d:"Короткое описание." },
```

`w`: `river` — река, `lake` — озеро, `reservoir` — водохранилище, `sea` — море (добавьте `tide:true`, если есть приливы). Список рыб — ключи из `FISH`.
